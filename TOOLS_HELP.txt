================================================================================
  scAgent 工具参数帮助文档
  版本: v0.1  |  工具总数: 9
================================================================================

  分析流程: QC → PCA/UMAP → SNN聚类 → 细胞注释
            └→ DimPlot / 标记基因可视化 / 细胞比例 / 热图 / 功能富集


================================================================================
  1. run_qc_for_all_samples  ——  单细胞质量控制
================================================================================
  用途: 对 data/rawdata/ 目录下所有 10X 样本执行完整的单细胞质控流水线。
        自动扫描数据目录，找到所有 10X 格式的样本，一次性提交给 R 后端处理。

  分析步骤:
    Step 1 - 数据导入（Read10X + CreateSeuratObject）
    Step 2 - 添加细胞元数据（线粒体百分比 + 核糖体百分比）
    Step 3 - QC 可视化（小提琴图 + 散点图）
    Step 4 - 过滤 + 多样本合并（subset → merge → 生成 batch 列）
    Step 5 - 归一化 + 高变基因筛选
    Step 6 - 高变基因可视化
    Step 7 - 标准化 + 线粒体回归
    Step 8 - PCA + Harmony 批次校正

  输入: data/rawdata/ 下的 10X 数据目录
  输出: data/qc/（图片、日志、.rds 对象）
  所有参数均为可选。

  参数名                类型      默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  project              str       scRNA_project     项目名称，决定输出文件前缀
  min_cells            int       3                 基因至少出现在多少个细胞中
  min_features         int       200               细胞至少表达多少个基因
  nfeature_rna_low     int       200               nFeature_RNA 过滤下阈值
  nfeature_rna_high    int       6000              nFeature_RNA 过滤上阈值
  percent_mt_max       int       5                 线粒体基因比例上限(%)
  percent_ribo_min     int       10                核糖体基因比例下限(%)
  run_harmony          bool      True              是否运行 Harmony 批次校正


================================================================================
  2. run_pca_umap  ——  PCA/UMAP 降维与可视化
================================================================================
  用途: 对 QC 完成的 Seurat 对象执行降维与可视化分析。
        自动从 data/qc/ 读取上一次质控的 Seurat 对象，运行 PCA 降维 +
        UMAP 非线性嵌入，生成 ElbowPlot 和 UMAP 散点图。

  分析步骤:
    Step 1 - 从 data/qc/seuratobject.json 读取 Seurat 对象
    Step 2 - 自动检测可用降维方法（harmony > pca）
    Step 3 - ElbowPlot 评估主成分贡献度
    Step 4 - RunUMAP 非线性降维
    Step 5 - DimPlot UMAP 可视化

  输入: data/qc/ 的 Seurat 对象
  输出: data/pca_umap/（图片、日志、.rds 对象）
  所有参数均为可选。

  参数名                类型      默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  project              str       scRNA_project     项目名称
  elbow_ndims          int       50                ElbowPlot 展示的主成分数
  umap_dims            str       "1:15"            UMAP 输入 PCA 维度范围
  umap_n_neighbors     int       30                UMAP 邻近数，越大越保留全局结构
  umap_min_dist        float     0.3               UMAP 点间最小距离，越小细胞越抱团
  dimplot_group_by     str       orig.ident        DimPlot 分组列名（按样本着色）


================================================================================
  3. run_snn_cluster  ——  SNN 图聚类分析
================================================================================
  用途: 对 PCA/UMAP 完成的 Seurat 对象执行 SNN 图聚类分析。
        自动从 data/pca_umap/ 读取上一次降维分析的 Seurat 对象，
        通过 FindNeighbors 构建 SNN 邻接图，再用 FindClusters 进行
        社区发现分群，确定每个细胞所属的聚类编号。

  分析步骤:
    Step 1 - 从 data/pca_umap/seuratobject.json 读取 Seurat 对象
    Step 2 - 自动检测可用降维方法（harmony > pca）
    Step 3 - FindNeighbors 构建 SNN 邻接图
    Step 4 - FindClusters 社区发现分群
    Step 5 - 聚类结果统计
    Step 6 - DimPlot UMAP 聚类图可视化

  输入: data/pca_umap/ 的 Seurat 对象
  输出: data/snn_cluster/（图片、日志、.rds 对象）
  所有参数均为可选。

  参数名                类型      默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  project              str       scRNA_project     项目名称
  findneighbor_dims    str       "1:15"            FindNeighbors 输入维度范围
  k_param              int       20                KNN 邻居数，稀有细胞群可适当降低
  resolution           float     0.8               分群分辨率，越大亚群越多
  cluster_algorithm    int       1                 聚类算法: 1=Louvain, 4=Leiden


================================================================================
  4. run_cell_type_annotation  ——  标记基因识别与细胞类型注释
================================================================================
  用途: 对 SNN 聚类完成的 Seurat 对象执行标记基因识别与细胞类型自动注释。
        自动从 data/snn_cluster/ 读取聚类结果，先运行 FindAllMarkers
        寻找每个聚类的标记基因（差异表达基因），再使用 SingleR 参考
        数据集进行自动细胞类型标注，最终将注释结果写入 Seurat 元数据。

  分析步骤:
    Step 1 - 从 data/snn_cluster/seuratobject.json 读取 Seurat 对象
    Step 2 - FindAllMarkers 寻找每个聚类的标记基因
    Step 3 - 标记基因统计 + 保存 CSV
    Step 4 - SingleR 参考数据集自动注释（小鼠用 MouseRNAseqData）
    Step 5 - 注释结果写入 Seurat 对象 meta.data
    Step 6 - DimPlot UMAP 细胞类型可视化

  输入: data/snn_cluster/ 的 Seurat 对象
  输出: data/cell_annotation/（图片、CSV、日志、.rds 对象）
  所有参数均为可选。

  参数名                类型      默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  project              str       scRNA_project     项目名称
  species              str       mouse             物种: mouse 或 human
  logfc_threshold      float     0.25              差异表达 logFC 阈值
  max_cells_per_ident  int       None              每聚类最多采样细胞数（None=不限）
  singler_de_method    str       classic           SingleR 差异分析方法: classic / wilcox / t


================================================================================
  5. run_dimplot  ——  DimPlot 细胞分群可视化
================================================================================
  用途: 对已完成细胞注释的 Seurat 对象生成 UMAP 降维散点图。
        从 data/cell_annotation/ 读取细胞注释结果，支持按多种元数据列
        着色（如样本来源、细胞类型），支持按样本拆分子图，方便对比
        不同样本/条件间的细胞分布差异。

  输入: data/cell_annotation/ 的 Seurat 对象
  输出: data/dimplot/（图片、日志）
  所有参数均为可选。

  参数名                类型        默认值                     说明
  ─────────────────────────────────────────────────────────────────────────
  project              str         scRNA_project              项目名称
  reduction            str         umap                       降维类型: umap, pca
  group_by             List[str]   [orig.ident, cell_type]    分组着色列
  split_by             str         orig.ident                 按该列拆分子图
  pt_size              float       0.3                        点大小
  label                bool        True                       显示聚类/细胞类型标签
  repel                bool        True                       标签防重叠


================================================================================
  6. run_marker_visualization  ——  标记基因表达可视化 (VlnPlot + DotPlot)
================================================================================
  用途: 对指定的标记基因绘制小提琴图（VlnPlot）和气泡图（DotPlot）。
        小提琴图展示单个基因在各细胞群中的表达分布（含散点），气泡图
        同时展示多个基因在各细胞群的表达水平（颜色）和表达比例（大小）。
        常用于验证细胞注释结果的准确性。

  输入: data/cell_annotation/ 的 Seurat 对象
  输出: data/marker_viz/（图片、日志）
  **marker_genes 为必须参数**，其余可选。

  参数名                类型        默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  marker_genes         List[str]   【必须】          需要可视化的基因名列表
  project              str         scRNA_project     项目名称
  group_by             str         cell_type         分组列名
  pt_size              float       0.1               小提琴图散点大小，0=隐藏散点
  ncol                 int         2                 多基因作图列数


================================================================================
  7. run_cell_ratio_viz  ——  细胞类型比例可视化 (堆叠柱状图)
================================================================================
  用途: 按样本统计各细胞类型的比例，绘制堆叠柱状图。
        从 Seurat 对象的 meta.data 中提取样本和细胞类型信息，计算
        每个样本中各细胞类型的占比，以堆叠柱状图展示。适合对比不同
        样本/条件间的细胞组成差异。同时输出 CSV 比例表。

  输入: data/cell_annotation/ 的 Seurat 对象
  输出: data/cell_ratio/（图片、CSV、日志）
  所有参数均为可选。

  参数名                类型      默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  project              str       scRNA_project     项目名称
  group_by_sample      str       orig.ident        样本分组的列名
  group_by_celltype    str       cell_type         细胞类型列名
  position             str       stack             柱状图类型: stack(堆叠) 或 fill(100%)


================================================================================
  8. run_heatmap  ——  标记基因热图 (DoHeatmap)
================================================================================
  用途: 对各细胞群的 Top N 标记基因绘制热图（DoHeatmap）。
        从 cell_annotation 步骤生成的 cluster_markers.csv 中提取每个
        聚类的前 N 个标记基因，对 Seurat 对象按细胞类型分组绘制热图，
        直观展示各细胞群的基因表达特征。支持随机抽样以加速渲染。

  输入: data/cell_annotation/ 的 Seurat 对象 + cluster_markers.csv
  输出: data/heatmap/（图片、日志）
  所有参数均为可选。

  参数名                类型      默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  project              str       scRNA_project     项目名称
  top_n                int       5                 每个聚类的 Top N 标记基因
  group_by             str       cell_type         分组列名
  sample_n             int       None              随机抽样细胞数（None=全部）


================================================================================
  9. run_enrichment_analysis  ——  功能富集分析 (GO/KEGG)
================================================================================
  用途: 对指定细胞群的标记基因做 GO 生物学功能富集分析。
        从 cluster_markers.csv 中提取目标细胞群的标记基因，调用
        clusterProfiler 的 enrichGO() 进行 GO 富集分析（Biological
        Process / Cellular Component / Molecular Function），生成
        柱状图展示显著富集的功能通路，揭示细胞群的生物学功能特征。

  输入: data/cell_annotation/ 的 Seurat 对象 + cluster_markers.csv
  输出: data/enrichment/（图片、日志）
  **cell_group_names 为必须参数**，其余可选。

  参数名                类型        默认值            说明
  ─────────────────────────────────────────────────────────────────────────
  cell_group_names     List[str]   【必须】          目标细胞类型名称列表
  project              str         scRNA_project     项目名称
  species              str         mouse             物种: mouse 或 human
  ont                  str         BP                GO 本体: BP/CC/MF/ALL
  qvalue_cutoff        float       0.05              q 值过滤阈值
  show_category        int         10                展示的 Top N 通路数


================================================================================
  调用说明
================================================================================

  - 所有参数均有默认值，不传则使用默认值（默认小鼠物种）。
  - 标记【必须】的参数需要 LLM 根据上下文推断并传入。
  - 工具 1-4 是分析流水线（有依赖顺序），工具 5-9 是独立可视化（均依赖工具 4 的输出）。
  - 各工具的输出目录:
    QC          → data/qc/
    PCA/UMAP    → data/pca_umap/
    SNN聚类      → data/snn_cluster/
    细胞注释      → data/cell_annotation/
    DimPlot     → data/dimplot/
    标记基因可视化 → data/marker_viz/
    细胞比例      → data/cell_ratio/
    热图         → data/heatmap/
    功能富集      → data/enrichment/
